## 🌟 Key Highlights & Features

- **🛡️ Enterprise Security Suite (18-Vector Defense)**:
  - Strict Content Security Policy (CSP) with `upgrade-insecure-requests`
  - Client-side sliding-window rate limiting (DoS / Brute-Force defense)
  - Anti-Clickjacking / UI Redressing framebusting protection
  - Anti-CSRF token verification
  - Deep binary magic-byte verification for file uploads (`%PDF-`, `PNG`, `JPEG`, `WEBP`)
  - SSRF protection blocking private IP & cloud metadata exfiltration
  - Input sanitization defending against XSS, SQLi, and Command Injection

- **🎮 Neural Arcade Suite (4 Interactive Simulations)**:
  - **Firewall Defender**: Defend against multi-tier cyber threat waves and malware packets
  - **Matrix Decrypter**: High-speed hex/cypher decryption simulation
  - **Quantum Neon Highway**: High-speed futuristic cyber highway dodging obstacles
  - **Neural Circuit Routing**: Route synaptic data packets through firewall gates

- **⚙️ Level-5 Administrative Console**:
  - Secure credential-gated admin portal with session context hashing and sliding-window expiration
  - Dynamic addition, modification, and deletion of **Skills**, **Certificates**, **Projects**, **Home Roles**, **Metrics**, and **Contact Links**
  - **First-in-Front Architecture**: Newly added skills, certificates, and projects automatically position at the very front/top
  - **Resume / CV Management**: Upload, preview, replace, or delete PDF resumes with instant Home section download button sync

- **📱 Multi-Device & Display Compatibility**:
  - Responsive across Mobile, Tablets, Desktops, 4K TVs, and Conference Projectors (10-foot UI optimization)
  - Mobile bottom navigation pill strip with auto-tour section transitions
  - Smooth page navigation and fluid cubic-bezier quintic transitions

- **👤 Dynamic Profile Favicon**:
  - Automatically binds Biswajit's profile picture to the browser title bar tab icon in real time

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Bisw0319/my-portfolio.git
cd my-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Build for production
```bash
npm run build
```
